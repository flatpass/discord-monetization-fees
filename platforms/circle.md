## Notes
- A secondary source read on 2026-08-02 put Circle at roughly 7% on some plans. Circle's own pricing page as read on 2026-08-23 states 2% / 1% / 0.5% on the three published tiers. The page is what this dataset carries; the change is logged in CHANGELOG.
- The pricing page states no card processing rate, so the all-in cost of a Circle sale cannot be computed from it.
- Circle hosts the community itself. A seller using it is not gating a Discord server.
