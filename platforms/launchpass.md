# LaunchPass

A paid-access layer for Discord, Telegram and Slack, billed per community.

| Field | Value |
|---|---|
| Website | https://launchpass.com |
| Pricing page | https://www.launchpass.com/ (plans are on the site; fee arithmetic is in the help centre at https://help.launchpass.com/en/) |
| Monthly fee | Free $0 (cannot charge members) · Premium $29/month per community · Ultra negotiated |
| % of each sale | 3.5% on Premium. 12.5% for owners who downgrade from Premium to Free. Ultra's 3.5% is negotiable. |
| Card processing | Stripe's rate on the seller's own connected account — additional |
| Fixed per transaction | Stripe's fixed fee (US $0.30) |
| Where the money settles | the seller's own Stripe account |
| Payout fees | none charged by LaunchPass; Stripe's payout terms apply |
| Payout timing / minimum | not stated |
| Other fees | none stated |
| Verified | 2026-10-06 · primary |

## Sources
- https://help.launchpass.com/en/articles/1548375-how-much-does-launchpass-cost — retrieved 2026-10-06 — "Total Fees ≈ Member Payment × 6.4% + $0.30", with a worked $50 example netting $46.50.
- https://www.launchpass.com/ — retrieved 2026-10-06 — "$29 / month +3.5% transaction fee"; the Free plan as "Basic Free Forever"; "Premium 14 days free trial".
- https://help.launchpass.com/en/articles/1745573-step-3-select-your-launchpass-plan-complete-pricing-guide — retrieved 2026-10-06 — "12.5% for owners who were on Premium and downgrade"; Ultra "Custom pricing".

Until 2026-10-06 this file listed an annual Premium price of $499. No LaunchPass page states one; the $499/year in its help centre is an example of what a seller might charge members.

## Notes
- **The Free plan cannot charge members.** It is a free tier for an unpaid community, not a free way to sell access.
- The 6.4% in LaunchPass's own worked example is 3.5% plus Stripe's US 2.9%. It is an all-in figure and LaunchPass presents it as one.
- Premium is billed **per community**, so a seller running two servers pays twice.
- Ultra is described as an enterprise tier for communities above 1,000 members or $50K in revenue.
- Payments run over Stripe Connect on the seller's own account.
