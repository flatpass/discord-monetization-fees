# XOE

A paid-access layer for Discord taking crypto (USDC on Base and Solana) and cards.

| Field | Value |
|---|---|
| Website | https://xoe.gg |
| Pricing page | https://xoe.gg/premium |
| Monthly fee | $0. "No monthly subscription." |
| % of each sale | 0% on card payments · 5% on crypto payments |
| Card processing | Stripe's rate on the seller's own account — additional. XOE adds nothing on top. |
| Fixed per transaction | Stripe's fixed fee (US $0.30) on card sales; none stated on crypto |
| Where the money settles | card payments to the seller's Stripe account; crypto to the seller's wallet |
| Payout fees | none stated; network gas applies to crypto |
| Payout timing / minimum | not stated |
| Other fees | none stated |
| Verified | 2026-08-23 · primary |

## Notes
- The two payment rails carry different rates: cards are 0% to XOE, crypto is 5%. A seller's effective cost depends on which rail their members use.
- Card payments are described as running through Stripe with PayPal, Apple Pay and Google Pay also accepted.
