# PayBot

A Discord bot that sells paid roles, charging a percentage of each sale and no monthly fee.

| Field | Value |
|---|---|
| Website | https://paybotapp.com |
| Pricing page | https://paybotapp.com (fees are stated on the homepage; there is no separate pricing page) |
| Monthly fee | $0 |
| % of each sale | 3% |
| Card processing | Stripe's rate on the seller's own connected account — additional |
| Fixed per transaction | Stripe's fixed fee (US $0.30) |
| Where the money settles | the seller's own Stripe account |
| Payout fees | none charged by PayBot; Stripe's payout terms apply |
| Payout timing / minimum | not stated; PayBot states funds land in the seller's Stripe as the sale clears |
| Other fees | none stated |
| Verified | 2026-08-23 · primary |

## Notes
- PayBot's own pages state that Stripe is connected over OAuth and that sales land in the seller's own Stripe account with no platform hold. Only PayBot's statements about PayBot are used here; the same page's figures for other platforms are not.
- PayBot's homepage does not publish a card processing rate of its own. The rate a seller pays is Stripe's, on the seller's account, in the seller's country.
- No payout schedule or minimum is published.
