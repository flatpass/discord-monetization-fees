# Skool

A hosted community platform with courses and paid membership. Not a Discord gate — a replacement for one.

| Field | Value |
|---|---|
| Website | https://www.skool.com |
| Pricing page | https://www.skool.com/pricing |
| Monthly fee | Hobby $9/month · Pro $99/month. A yearly billing option is offered, described on the page as two months free. |
| % of each sale | Hobby 10% + $0.30 · Pro 2.9% + $0.30, and 3.9% + $0.30 on Pro transactions above $900 |
| Card processing | included in the transaction fee: Skool is the merchant and publishes no separate processing line |
| Fixed per transaction | $0.30, per the help centre (the pricing page shows the percentages only) |
| Where the money settles | Skool, then a weekly payout through a Stripe Express account Skool creates |
| Payout fees | not stated |
| Payout timing / minimum | weekly on Wednesdays; funds become available 8 to 14 days after a payment |
| Other fees | Growth Boost: 30% commission on a customer Skool's own promotion brings, on by default and can be switched off. Transaction fees are not refunded when a payment is. |
| Verified | 2026-10-06 · primary |

## Sources

- https://help.skool.com/article/86-subscriptions-faq — retrieved 2026-10-06, updated 2026-09-29 — "2.9% + 30c /transaction for transactions up to $899 USD. 3.9% + 30c /transaction for transactions above $900 USD."; Hobby "10% + 30c /transaction for all transactions"; "All payment processing happens on the Skools merchant."; "You only pay a 30% commission if Skool gets you a customer."

## Notes
- The pricing page states each plan's fee as a single percentage. Skool's help centre states it in full, with the $0.30 and the higher band above $900, and is what this dataset carries since 2026-10-06.
- A reading recorded on 2026-08-02 had the same Pro figures. The 2026-08-23 reading looked at the pricing page alone, found neither, and recorded both as not stated; the help centre settles it. Logged in CHANGELOG.
- Skool adds EU VAT on top of the member's price.
- Skool hosts the community itself. A seller using it is not gating a Discord server.
